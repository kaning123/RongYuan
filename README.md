# RongYuan - A simple PYPI source mamager.

## Install

To install:
```bash
python -m pip install git+https://github.com/kaning123/RongYuan.git
```

## Use

To boot server, you can run a simple command below:
```bash
python -m rongyuan <Optional:URL_FilePath>
```

### How to write a URL file

Is simple to create your own private URL File like below:

```
https://example.pypi.mirror1
https://example.pypi.mirror2
...
```
